# WCAG 2.2 AAA: how calenda11y meets each success criterion

Every criterion at levels A, AA and AAA, whether it applies, how calenda11y meets it, and the evidence. "Automated" points to tests that run in CI on every change. "Manual" items are checked before each release using [the manual checklist](manual-checklist.md).

**Scope.** This covers every page calenda11y serves: public pages, forms, emails and admin. It doesn't cover third-party pages people pass through: Stripe Checkout and the Stripe customer portal (payments), and Cloudflare Turnstile (spam check). The accessibility statement names these. Event names, summaries and descriptions are written by organisers. The site's own handling of that content is in scope, but its wording is not (see 3.1.5).
